# Dokumentasi Praktikum Pemrograman Web (OBE)

## Informasi Mata Kuliah
* **Mata Kuliah:** Praktikum Pemrograman Web
* **Nama Proyek:** Proyek Praktikum Pemrograman Web - Outcome-Based Education (OBE)
* **Nama Repositori:** `pemweb-obe`

---

## Ringkasan Proyek Praktikum
Repositori ini disusun khusus untuk menyimpan seluruh modul, latihan, dan tugas praktikum mata kuliah Pemrograman Web berbasis kurikulum *Outcome-Based Education* (OBE). Berkas di dalamnya mencakup struktur halaman web dasar (HTML5) serta skrip pemrograman yang dijalankan pada *environment* server lokal.

---

## Spesifikasi Teknologi
* **HTML5** – Penyusunan tata letak dan elemen struktur web praktikum.
* **PHP & Apache** – Pemrosesan skrip *backend* dan *web server* lokal via Laragon.
* **Git & GitHub** – Sistem kontrol versi (*Version Control System*) untuk pengelolaan repositori praktikum.

---

## Petunjuk Menjalankan Praktikum via Laragon

1. **Persiapan Lokasi Folder:**
   * Pastikan aplikasi Laragon telah terpasang di komputer.
   * Letakkan folder repositori praktikum ini pada direktori: `C:\laragon\www\pemweb-obe`.

2. **Aktivasi Server Lokal:**
   * Buka aplikasi **Laragon**.
   * Tekan tombol **Start All** untuk mengaktifkan modul Apache dan MySQL.

3. **Membuka Hasil Praktikum:**
   * Buka aplikasi browser (Google Chrome / Microsoft Edge).
   * Ketikkan URL lokal proyek praktikum pada bilah alamat.

---

## Alamat URL Lokal
Halaman praktikum dapat diakses secara lokal melalui tautan berikut:
* `http://localhost/pemweb-obe/`

---

## Ringkasan Catatan HTTP
* **200 OK:** Request berhasil.
* **301/302:** URL dipindahkan (permanen/sementara).
* **404:** File/halaman tidak ditemukan.
* **500:** Error internal pada server.
